# 原生线程状态聚合验证

Windows x64 外置 LLVM 开发构建，`make all -j6` 返回零。编译器 SHA256：`13b5b19d9b4318669f63944871a1ad80bc9ea0d6e2f9b14013266471870b69a0`。

将六项线程局部状态聚合到一个线程局部对象，保留各线程独立的当前上下文、数据容量索引、回调深度、浮点返回标记、逻辑步数与清理标记。没有改成进程共享状态，没有修改公开运行时 ABI。此处仅记录行为验证，性能收益须由后续跨语言测量确认。

三项实际验证脚本退出码均为零，原始日志随目录保存：

- `python tests/chali_aot.py`：包括集合种类与深复制、浮点、opcode 移动／销毁、具名导出、全局资源初始化与清理、检查模式越界。
- `python tests/chali_native_callbacks.py`：具名及内联函数、复制／移动捕获、float32、bool、void、可变引用、高阶重入及 panic 穿过 C 帧传播。
- `python tests/chali_thread_wait.py --chali <本轮编译器>`：等待超时不消费句柄、重复等待诊断及工作线程失败传播。

静态 LLVM 与交叉运行时尚未重建，本轮不声称这些变体已通过验证。
