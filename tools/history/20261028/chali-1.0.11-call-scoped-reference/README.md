# 含调用函数的基础标量取址精化

Windows x64 外置 LLVM 编译器 SHA256：`1a9fc19df0808b4f5c8d11af3f8d4d615cef0d42828a357e48b2572119e74868`。

函数内取址集合扩展到普通调用，保留显式 &、move、迭代器及 getOption 接收者的需求。闭包、defer、转换和所有拥有类型继续保守处理，只精化整数／浮点／布尔／字符；文法、类型与借用规则不变。CHALI_NO_CALL_SCOPED_REFERENCE_STORAGE=1 关闭本轮含调用精化，CHALI_NO_SCOPED_REFERENCE_STORAGE=1 关闭全部精化。

variants.json 为修改前及 12 组分配器／检查／开关对照：含调用的 calledValue 隐藏分配由一降零，关闭相应路径恢复一；真实跨调用借用、move、遮蔽、标量泛型及拥有字符串副本行为一致。完整 AOT、同步 C 回调、泛型单态化、引用值综合样例、引用组合、24 项资源生命周期、集合传参／返回／复制以及 45 项拒绝／41 项允许的借用控制流与多诊断通过，未绑定引用保留原错误。六项特征只执行 ChaLi 的无计时模型校验，通过。

旧严格引用逃逸专项的既有限制见上一里程碑目录，未在这里伪报整套通过；没有修改或削弱测试断言。旧测试的 WORK 仅在验证进程中转至仓库 tmp。

当前最终门槛按用户最新要求改为逐项快于 Lua且耗时不超过 C++ O2 的 1.05 倍。此前 O3 数据保持历史标签，其他语言已有参考不重复评测。此时本轮性能收益未测量，下一步仅复测 ChaLi。
