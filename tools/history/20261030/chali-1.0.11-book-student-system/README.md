## 修正与边界

可视检查曾发现正文 #borrow 被错误识别为章标题，现按 Markdown 标题空格边界修正，并检查每章只生成一个章标题。图片限制页高，图注与图片保持同页。首轮 UI 测试暴露排序箭头影响可访问名称，现已隐藏装饰箭头并复验。

初轮 make 的 uname 辅助探测警告记录在原始构建日志；补全当前命令 PATH 后最终构建检查成功。没有把这些过程改写为首轮无问题。

认证当前依赖 Windows CNG 的 C:/Windows/System32/bcrypt.dll；其他操作系统或安装位置需要相应适配。应用是本机 HTTP、单进程串行示例；部署依赖与功能限制按项目 README。声明宏、其余宏增强、完整标准库预编译及 C 胶水迁移继续留在 TASK.md。

sha256.json 对文本按 UTF-8、去 BOM、统一 LF 核对，PNG 按真实字节核对；provenance.json 中的 EXE 与 PDF 摘要始终按二进制字节计算。
