# 1.0.11 宏固定参数类别阶段验收

生产源码 4f04ad610915fb6548e82c6398a2c502a4acc0df。版本 1.0.11，Windows x64 外置 LLVM；被测编译器摘要、开始验证时的干净工作区及内嵌核心摘要见 macro-categories-identity.json。原始性能基线没有重新测量。

固定参数支持 value、expr、ident、type、stmt、block。value 在展开体前单次求值并复用副本；expr 按语法放置位置执行，未使用时不执行。未标注参数和显式借用保持兼容；引用仅可标注 value。带类别变参、pattern/item、结果类别及其他宏增强仍由 TASK.md 保留，不能据本记录声称整个宏增强已完成。

新专项覆盖标准库路径 15 个程序与原始路径 13 个程序，包括求值次数／顺序、未使用值、修改副本、可写／只读借用、混合与双向嵌套转发、#res 组合、名称导出、语句与块、枚举类型、泛型／接口类型及跨模块同名泛型。类别错配和不支持的组合均拒绝。

泛型类型片段暴露了两处配套问题：结构化泛型解析生成的名称未沿用已登记的规范名；同模块重名模板采用内部键后，结构化片段未按模块和源码名查找。两处均修复，跨模块正例通过。早期构建的失败与复验日志单独保留；这些草稿未逐轮记录二进制摘要，不重标为最终编译器。最终身份只对应本批门禁。

模块相关和跨模块抽样共 36 项，原批次 35 通过、1 失败、0 跳过。第 17 项失败是新测试要求签名中的空白格式，而实际 LSP 正确保留源码原文。按维护约定忽略非语义空白，并增加当前参数标签范围检查后，完整 LSP 语义套件复验通过；原失败结果没有覆盖。retest.json 记录复验测试摘要，生产编译器未改变。这不是整仓全量门禁。

验证包括全部宏套件、LSP 补全／签名／预览／高亮、内嵌单元完整性与往返、独立导出编译器完整构建和新类别执行、书稿程序与 LaTeX 一致性、接口及原生回调抽样、配套泛型全部相关套件、默认模块与命名作用域，以及文档／EBNF／关键字／变更历史检查。具体命令和原始输出见 macro-categories-gates.jsonl、gates/results.json 与逐项日志。

独立导出的八个关键源码与当前仓库逐文件比较一致（仅归一 CRLF/LF），涵盖宏类别注册、签名、来源扫描及两项类型片段修复，摘要见 macro-categories-exported-sources.json。

泛型函数返回值在 checked／unchecked AOT 下的逐案例结果、输入摘要及预期拒绝证据见 generic-function-return-report.json；这份功能报告从临时目录移出后保留，生成的程序与中间文件不保留。
