# Obj 句柄固定槽

编译器 SHA256：31a3954c197b4f4bdd0cc09bf614da6f9f63b6d717b9026e621c58dec39ef842。

对象表为 Obj 添加 32 个不搬动的固定槽，按完整逻辑句柄选择并核对身份。槽位冲突或关闭时沿原 std::map 回退；不驱逐其他活跃句柄，不复用逻辑身份。NativeRecord／闭包／RawStorage 沿原表，宿主记录的 dispose 顺序保留。CHALI_NO_OBJECT_INLINE_SLOTS 关闭本优化，指针快照共享另由原独立开关控制。

真实系统 malloc 单测：96 个同时活跃句柄，固定槽与冲突回退、4096 次不同身份的创建／释放、相同槽位的旧身份拒绝、重复释放、零句柄、NativeRecord 留在原表及最终 liveBlocks=0 全部通过。4096 次短期指针副本，表节点分配从 4096 次减少到 128 次；COW 隔离对照仍为 64 次复制分配 64 对 128。

两种分配器 × 快照共享／原复制 × 固定槽／原表，共八组 checked run 与 unchecked AOT 通过。完整 AOT、Any 泛型、集合复制、同步回调和 Map 迭代器通过。运行时资产更新并重建；最终全量 CI 尚未执行。

正式接口计时待补。相关测试结束后 CPU 三次采样为 9%、13%、10%，机器仍有背景活动；按用户允许的功能优先规则继续优化，不将计数或试运行冒充性能结果，不宣称达到 10 ms。已保存原始 CPU 采样，未执行参考语言基准。
