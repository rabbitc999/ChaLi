# 后续地址视图的摊销提升

前一轮四项顺序查找提高了字符串速度，但固定数组由 10.437 ms 回退到 22.451 ms。当前修改不掩盖该数据：首项命中保持直接返回，不写额外计数；后续项累计每 32 次命中才把当前视图与首项交换。完整复制描述符及代次，保留所有范围与存活检查，不搬动用户数据。

CHALI_NO_AOT_ADDRESS_PROMOTION 关闭提升，保留前一轮四项轮换策略；单项和禁用缓存开关继续有效。上下文 reset 清空四项视图和两个计数。实现直接用 C++ 发射 LLVM 指令，未增加胶水或四元式优化。

实际编译器 SHA256：f214994585070ea8a92535869e596b02b5ced4dacf6c8cacda7473c9c350f328。资产重新生成并重建后，八组分配器／策略在 checked run 与 unchecked 动态库中通过；同一宿主线程跨总计 512 次初始化／销毁，每轮两个种子。用例含五块交错分配，随后两个不同缓冲区各连续读取 96 次，覆盖实际提升路径。

String 缓冲区八组及六类错误／六类禁止修改、同步回调重入与 panic、完整 AOT 专项全部通过。Python 和 CI shell 语法检查通过。实际 LLVM 原语摘录包含三处交换分支及上下文 reset，可对照关闭提升时无交换分支。

本轮不声称性能提高。提交后只复测受影响 ChaLi 数组及字符串，参考语言不执行；最终性能目标及全量门禁仍未完成。
