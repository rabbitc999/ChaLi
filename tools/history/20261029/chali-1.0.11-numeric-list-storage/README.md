# List 非拥有数值连续存储

纯数值追加在空的新 List 上启用连续 ScalarResult 槽，每槽包含 64 位数值位模式及浮点标记。本机 sizeof 为 16 字节，原 NativeStoredValue 为 104 字节。覆盖 bool、char、各宽度有符号／无符号整数及 float32/64，保留现有形参转换与 IEEE754 位模式；不是按各类型位宽压紧，也尚未取消逐元素原生调用。

长度、容量、预留、结构守卫、交换、移出丢弃及数值读取可直接处理连续槽。其他操作物化回原通用槽，保留长度和容量；物化完成前不改变活跃布局，旧数值缓冲区保留到 drop。扩容仍可回收被替换的缓冲区。复杂值、元素借用、迭代和兼容宿主接口沿旧路径；Map/Set 元素布局未改。最大容量暂沿通用布局保守上界，精确布局上界仍是 TASK 的未完成项。

记录布局身份递增到 ArrayList/Set/Map.2，避免跨库将不同版本私有记录按相同 ABI 解释。CHALI_NO_NUMERIC_LIST_STORAGE=1 提供通用存储对照。
