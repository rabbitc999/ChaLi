# List 数值缓冲区 LLVM 直接读写

以稳定的 ScalarListHeader 暴露数值数据、有效长度和容量；底层按完整容量构造无所有权数值槽，LLVM 只在已构造范围内读写和更新有效长度。复制构造沿原标准容器规则取有效长度为新容量，赋值保留足够的已有容量；扩容成功后更新头部，clear 和布局回退保留缓冲区直到 drop。

AST 后端将符合布局要求的数值追加和读取直接连接始终内联的 LLVM 原语。检查完整句柄、对象表代次、有效下标及剩余容量；命中时无逐元素原生调用。失效、容量不足、非数值布局及动态数值种类不适用时使用原宿主入口。CHALI_NO_AOT_NUMERIC_LIST_VIEWS 可关闭 LLVM 视图，通用返回 ABI、自举追加回退和复杂值保持可用。

代次由 ObjectStore 统一拥有。NativeCallContextImpl::nativeRecord 借用记录与释放路径使代次失效，经现有不透明宿主服务 native.rev.v1 注入根及子线程的上下文；不识别服务的宿主禁用视图。不增加 NativeCallContext 虚函数，不依赖各动态库私有 TLS 代次。计数溢出后保持零并永久禁用；原生模块初始化、结束及上下文切换清空 LLVM 缓存。各线程使用隔离的对象表。记录布局身份为 ArrayList/Set/Map.3。
