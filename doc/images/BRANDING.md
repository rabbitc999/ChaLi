# ChaLi 吉祥物与视觉素材 / Mascot and visual assets

ChaLi 的吉祥物是一只奶油白色小猫，佩戴蓝色项圈和金色吊牌，与柔和蓝色、金黄色积木搭配。整体采用温暖、简洁的风格；应用图标以小猫和积木为主体，不使用大写 C 作为主体，也不采用魔法元素。

- `chali-logo.png`：语言标志，与 `../../vscode/icon.png` 使用同一图像。
- `chali-poster.png`：宣传图，用于无音频宣传片。

这些位图由图像生成工具制作，替换原先由 Python 绘制的标志；旧 `tools/make_icon.py` 和未被构建引用的 `chali.ico` 已移除。

The ChaLi mascot is a cream-white kitten wearing a blue collar and golden tag, accompanied by soft blue and golden building blocks. Keep the visual style warm and simple. The application icon features the kitten and blocks; avoid a large letter C or magical elements.

`chali-logo.png` and `../../vscode/icon.png` share the same artwork. `chali-poster.png` is the promotional illustration used in the silent film. These assets were created with an image generation tool and replace the former Python-drawn branding.
