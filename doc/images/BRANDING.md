# ChaLi 吉祥物与视觉素材 / Mascot and visual assets

ChaLi 的吉祥物是一只驼棕色（浅棕）卡通小猫：深藏青色粗描边，珊瑚粉色耳尖与鼻子，白色口鼻与胸口，大圆眼带白色高光，尾巴上翘。标志为扁平插画风格、背景透明；不以大写 C 作为图标主体，也不采用魔法元素。

- `chali-logo.png`：语言标志，透明背景 PNG（1254×1254，带 alpha 通道），与 `../../vscode/icon.png` 使用同一图像。
- `chali-poster.png`：宣传图 / 背景图（1536×864，16:9）。明亮书桌场景：小猫坐在笔记本电脑旁，屏幕上是猫的图标界面，周围有蓝色与金黄色积木、咖啡杯、绿植和摊开的速写本；小猫佩戴深蓝项圈与金色 C 吊牌，右上角为深蓝色「ChaLi 1.0.0」字样。用于无音频宣传片，也作为演示文稿的封面主视觉。

这些位图由图像生成工具制作，替换原先由 Python 绘制的标志；旧 `tools/make_icon.py` 和未被构建引用的 `chali.ico` 已移除。2026-11-12 起标志与宣传图统一为驼棕色扁平猫形象，旧版为奶油白色 3D 小猫。

The ChaLi mascot is a tan (light brown) cartoon kitten: thick dark-navy outlines, coral-pink ear tips and nose, a white muzzle and chest, large round eyes with white highlights, and an upward curled tail. The logo is a flat illustration on a transparent background. Keep the visual style warm and simple. The application icon features the kitten; avoid a large letter C as the main subject and avoid magical elements.

- `chali-logo.png`: the language mark, a transparent PNG (1254x1254, with alpha channel); `../../vscode/icon.png` shares the same artwork.
- `chali-poster.png`: the promotional illustration / background artwork (1536x864, 16:9), a bright desk scene with the kitten beside a laptop whose screen shows the kitten icon, surrounded by blue and golden building blocks, a coffee cup, a plant and an open sketchbook. The kitten wears a dark-blue collar with a golden "C" tag, and "ChaLi 1.0.0" appears in dark blue in the upper right. Used for the silent film and as the cover artwork for presentations.

These bitmaps were created with an image generation tool and replace the former Python-drawn mark; the old `tools/make_icon.py` and the `chali.ico` that was not referenced by the build have been removed. Since 2026-11-12 the mark and poster use the tan flat-illustration kitten; the previous version was a cream-white 3D kitten.
