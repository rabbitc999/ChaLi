把成绩计算拆成函数后，可以分别验证计算结果、参数传递和错误边界。本章先使用普通数值参数，引用和资源类型分别在第 7、8 章引入。

## 4.1 参数与返回类型

函数声明写出返回类型、名称和参数表。调用时按参数顺序提供实参，结果可用于初始化或其他表达式。按值参数对可复制值使用独立值语义，函数内修改参数不会据此写回调用方绑定。

<!-- verify-book -->
```chali
int64 addBonus(int64 score, int64 bonus)
{
    score += bonus;
    return score;
}

void main()
{
    int64 score = 70;
    int64 result = addBonus(score, 5);
    println("{} {}", score, result);
}
```

```text
70 75
```

## 4.2 重载、默认参数与变参

重载根据参数类型和数量选择候选；返回值类型不单独决定重载。默认参数补充省略的尾部实参。变长参数用于数量可变的调用，其元素类型及展开规则见语言参考。候选不唯一时应补足类型或调整接口，不依靠声明先后决定结果。

## 4.3 多个结果与带值控制流

多个结果可组成元组，调用方用解构接收。return 后面也可以是产生值的块、条件或循环；yield 给最近接收值的控制表达式提供结果，return 结束函数。先辨认退出的是函数还是控制表达式，再判断清理和后续执行位置。

<!-- verify-book -->
```chali
int64 fromBlock()
{
    return
    {
        int64 local = 3;
        yield local;
    };
}

int64 choose(bool first)
{
    return if (first)
    {
        yield 5;
    }
    else
    {
        yield 6;
    };
}

int64 fromMatch(int64 item)
{
    return match (item)
    {
        0 => { yield 7; }
        _ => { yield 8; }
    };
}

int64 fromLoop()
{
    return loop
    {
        yield 9;
    };
}

void main()
{
    println("{} {} {} {}", fromBlock(), choose(false), fromMatch(0), fromLoop());
}
```

```text
3 6 7 9
```

## 4.4 把接口写成调用契约

只读输入、需要写回的对象和可能失败的计算应在签名中区分：分别使用合适的值／引用参数以及 Option／Result 返回。main 作为可执行入口返回 void，可无参数，或接收 List<String> 命令行参数。原生库导出入口另见第 21、24 章。

## 4.5 习题

1. 调用 addBonus 后原成绩是多少？
2. 增加同名的 float64 版本并显式选择实参类型。
3. 用元组返回总分和人数。
4. 解释 yield 与 return 的接收者。

### 参考解答与验收要点

1. 仍为 70，返回结果为 75。
2. 参数表不同，调用时核对重载选择。
3. 声明元组返回类型，在调用方解构并分别核对。
4. yield 对应带值控制表达式；return 对应函数。

## 4.6 番外：三调辨妖函数

改写自《西游记》三打白骨精一节。人物的“辨妖”仅作函数输入输出的比喻。

却说师徒行到白虎岭，唐僧腹中饥饿，八戒便写了一道辨妖函数，拍胸道：“师父放心，徒弟这个接口，已经验收过两遍。”悟空看时，函数腹内只有一句固定的“不是妖”。

那白骨精头一次变作少女，提着饭来。八戒调用函数，果然不是妖；第二次变作老妇，函数仍说不是妖。唐僧喜道：“两次调用，结果一致，可见十分稳定。”悟空道：“师父，那石头扔进井里也很稳定，不见得会辨妖。”

第三次老翁到了，八戒还欲调用。悟空一棒拦住终端，问：“你这一回把来者的什么信息传了进去？”八戒道：“前两次都没传，到了第三次才加参数，岂不破坏兼容？”

唐僧听见“兼容”二字，便要念紧箍咒。沙僧忙上前道：“大师兄说得是。调用次数多，不等于分支覆盖多。”

悟空将观察结果作为参数，把每条判断路径写明。妖精无计，只得化作原形。八戒仍不服：“我的函数也有返回值！”悟空笑道：“你那叫占卜，不叫计算。”

后来八戒补上单元说明：“无论传入什么，都返回不是妖。”这回沙僧倒说接口与实现一致了，只是师父坚决不肯再拿它买盒饭。

### 技术对照

局部变量只在其作用域内有效。按值参数修改的是自己的值；要修改调用者对象，接口必须明确使用相应可写引用。返回值应覆盖函数承诺返回的路径。
