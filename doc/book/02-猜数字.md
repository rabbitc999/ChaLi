# 第 2 章 猜数字

<!-- LANGUAGE NAVIGATION -->
[English](en/02-guessing-game.md) · **简体中文**
<!-- END LANGUAGE NAVIGATION -->

我们来写一个会回答问题的程序。它心里有一个数，你输入一个猜测，它告诉你偏小、偏大，还是正好猜中。先把答案固定为 42；这样每次运行都能比较同一组输入。

## 2.1 先比较一次

暂时不读键盘，在 main 的花括号里写下面三条语句：

```chali
int64 answer = 42;
int64 guess = 30;
println("{}", guess < answer);
```

第一行保存答案，第二行保存一次猜测。第三行里的 `<` 比较两边的数，产生一个真假值；当前结果为真，默认输出显示为 1。把 30 改成 60，结果会变成 0。现在程序已经能够判断大小，只是还没有用文字回答。

## 2.2 把判断换成提示

在刚才两条声明后面，用下面的分支替换 println：

```chali
if (guess < answer)
{
    println("small");
}
else
{
    println("not small");
}
```

if 先计算圆括号里的条件。条件为真，就执行第一对花括号里的调用；否则执行 else 后面的调用。一次只走其中一边，所以不会同时输出两条提示。

这个版本还把“偏大”和“相等”混在一起。下面再增加一次比较，并把整个判断放进循环。先阅读完整程序，再按后面的三段追踪它。

## 2.3 每轮接收一个猜测

保存为 guess.chl，运行后依次输入 30、60、42，每个数字后按回车。预期输出不包含终端对输入的回显。

<!-- verify-book-input: "30\n60\n42\n" -->
```chali
void main()
{
    int64 answer = 42;
    loop
    {
        int64 guess = inputInt();
        if (guess < answer)
        {
            println("small");
        }
        elif (guess > answer)
        {
            println("large");
        }
        else
        {
            println("found");
            break;
        }
    };
}
```

```text
small
large
found
```

第一段只做一次：进入 main，给 answer 保存 42。它在循环外，因此所有猜测都与同一个答案比较。int64 是这里使用的整数类型，下一章再看它和其他类型的区别。

第二段从 `loop` 开始。loop 没有条件检查，每轮都执行循环体；这里每轮都先调用 inputInt，从键盘取得新的 guess。这一行放在循环里，才会每轮重新读取。

第三段是三个互斥的回答。第一次输入 30，进入小于分支，打印 small 后开始下一轮。第二次输入 60，第一个条件不成立，elif 才比较是否大于答案，于是打印 large。第三次输入 42，两个比较都不成立，进入 else。

else 中先打印 found，再执行 break。break 退出当前循环；没有它，程序即使猜中了也会继续等待输入。`elif` 也可以写成 `else if`，含义相同。

## 2.4 给小游戏增加一项功能

想统计次数，先想清楚这个数要活多久。它需要记住前几轮的结果，所以应该像 answer 一样在循环外声明。在读取 guess 之后加一，在猜中的分支打印它。把计数器放进循环会每轮重新开始，最后看到的就总是一次。

这段程序要求输入有效整数。非数字输入与输入结束是另一个问题，我们在第 14 章用错误返回处理它。现在可以先练习猜中、偏大、偏小三条正常路径，不把“输入无效”和“猜得不对”混在一起。

## 2.5 习题

1. 第一次输入 42，程序会打印什么？
2. 按上面的思路记录并打印猜测次数。
3. 把 elif 改成 else if，使用相同的三次输入核对结果。
4. 去掉 break 后，为什么猜中也不会结束？

### 参考解答与验收要点

1. 只打印 found，然后退出循环。
2. 循环外初始化为 0，每次读取成功后加一，猜中时应得到 3。
3. 两种拼写形成相同的条件链，仍应依次显示 small、large、found。
4. while 的条件仍是真，而唯一显式退出循环的语句被删掉了。

## 2.6 番外：龟兔猜数字

改写自伊索寓言《龟兔赛跑》。

兔子常常讥笑乌龟猜得慢。乌龟不服，说：“你跑得虽快，也未必猜得准。目标一到一百，我们比一比。”狐狸做裁判，先把答案藏进一个整数里，又特别声明：输入字符串不算猜。

兔子跳到终端前，先猜九十九，再猜二，接着输入一个“很大的数”。解析器报错。兔子觉得自己已经进行了三轮高强度推理，便躺到树下，说剩下的七十多次机会足够睡个午觉。

乌龟先猜五十。裁判说小，它便删去一半候选；猜七十五，大，又删一半。每走一步，都核对边界，连同一个错误也不肯重犯。狐狸看得直打呵欠：这个算法连戏剧冲突都对半砍。

兔子醒来，见乌龟还在纸上写字，笑道：“这么久才猜了六次！”说罢又输入九十九。裁判答：“这个分支你早来过。”

乌龟此时已写下答案。兔子奔到终点，发现验收表只有一行：“正确，七次以内。”它气得跳脚，说自己的输入速度遥遥领先。狐狸点头，把“每秒错误次数第一名”的奖牌挂在了它脖子上。

### 技术对照

输入失败与猜错是不同分支。先检查输入转换结果，再比较大小；上下界更新必须保留尚有可能的候选，并保证每轮取得进展。
