# 第 21 章 C ABI 与宿主互调

<!-- LANGUAGE NAVIGATION -->
[English](en/21-c-interop.md) · **简体中文**
<!-- END LANGUAGE NAVIGATION -->

已有 C 库能提供数据库、系统服务和成熟算法，但跨过语言边界以后，双方必须对参数宽度、布局、指针、返回值与资源责任达成一致。一个能被找到的符号，并不自动等于一个能被正确调用的函数。

本章按原型声明、数据封送、资源与错误、同步回调的顺序建立接口。短片段只展示声明方式，完整运行还依赖真实动态库及相符目标；部署时同样需要带上应用实际依赖的库。

## 21.1 声明真实的宿主原型

接入外部库时，从库提供的真实 C 原型开始，而不是先猜一份容易编译的 ChaLi 声明。先确认函数名、返回值和每个参数，再核对整数宽度、指针方向及结构体布局；符号存在只是第一步。

#abi 把这份语言侧声明与调用约定、动态库和导出符号连接起来。int64 不能统一代替所有平台的指针或整数，声明也不会自动修正不匹配的外部实现。

完整可运行例程见 [C ABI 缓冲区示例](../examples/abi_buffers/demo.chl)；需要先构建其 native.c 动态库。

例如 C 的 int32_t bump(int32_t *value) 需要按真实返回类型和指针原型声明；若 C 原型实际返回 void，就不能照抄 int32 返回。下面的声明对应 void bump(int32_t*)，调用传入 &value：

```chali
#abi("C", "./native.dll", "bump")
void bump(int32 mut& value);
```

### 代码详解

#abi 将下面的声明关联到指定动态库中的 C 符号 bump。三个字符串分别说明调用约定、库路径和符号名；`void bump(int32 mut& value);` 只有原型，末尾分号表示这里没有 ChaLi 函数体。宿主实际实现必须与这个签名及目标平台 ABI 相符。

mut& 表达外部函数可能写回传入的整数来源，void 表示没有普通返回值。该片段不能独立运行，还需真实 native.dll、相符的导出符号与调用代码。不能仅将文件后缀改为另一系统的形式就认为已完成移植，也不能把 ChaLi 逻辑地址自行当成 C 指针。


库路径相对声明所在源文件解析，本地函数名可以与导出符号名不同。完整结构体、数组和可选引用示例由本节链接工程提供。

既有宿主注册表也支持 impl 类型 : 接口 = 宿主符号;，例如 demo_counter_from_uint 的关联方式见 [cpp_glue.chl](../../example/samples/cpp_glue.chl)。这种注册入口需要已有宿主实现，不能把符号名当成任意 C 函数指针。

## 21.2 引用、数组与封送

单对象引用与数组参数不是同一种声明。宿主数组约定需要长度和有效缓冲区；返回数组必须使用支持的长度标注。语言侧数组对象本身不能直接当作机器缓冲区地址。变长数据还要核对由哪一方分配、复制、修改和释放。

## 21.3 资源和错误边界

检查库的错误返回值，并在所有返回路径关闭句柄。宿主返回的借用若指向会复用的内部缓冲区，应按文档规定取得稳定副本。原生库可以违反自身原型或写越界；语言的静态检查不能验证外部二进制的全部行为。

## 21.4 函数值与同步回调

同步回调沿受支持的宿主上下文与函数值接口调用，需核对参数、返回值、闭包、重入和错误传播。捕获环境的函数值不是机器函数指针，不能只改类型就获得合法 C 回调。部署还必须准备实际使用的外部库及许可证。

### 小结

宿主接口可以按“原型是否一致、数据如何过边界、谁拥有资源、错误如何返回”逐项审查。输入与输出指针、单对象引用和连续数组、借用缓冲区与拥有副本，都要明确区分。

带环境的函数值通过受支持回调协议调用，不能靠强转成机器指针省略环境与错误传播。进入底层时把复杂性封装在小范围，向业务层提供可检查的普通接口。

## 21.6 番外：借来的梨树与指针

改写自《聊斋志异·种梨》。

有乡人货梨于市，颇甘芳，价腾贵。有道士求一梨，乡人叱之。旁人买而赠焉。道士食尽，留核，掘地埋之，俄而一树，枝叶扶疏，累累有梨，请众人任取。

乡人看得心热，忙将树的位置记在纸上，欲待散场，日日来摘。道士斫树而去，乡人依旧址伸手，只抓得一把尘土。乃怒曰：“这地址未变，梨何故不在？”

道士回身曰：“君记住地址，未曾取得所有权。对象既去，地址尚存，有何稀奇？”乡人仍不服，把旧指针换一个更大的整数，以为范围变宽，梨便能多活几天。

旁一木匠接过枝条，约定只在眼前加工。乡人又将这口头保证写成永久回调，待人散尽，遥唤木匠，哪还有上下文应答？

道士指着三个字教他：“谁创建，谁释放；借多久，何时用。跨语言的墙，挡不住生命周期的账。”

乡人回看梨车，梨已尽失，连车把也不知去了哪里。他捏着那张地址单，终于明白：ABI 对上，不过说明门牌格式认得；门后有没有人、谁有权搬家，仍须另外说清。

### 技术对照

ABI 一致只是互操作的前提之一。指针、字符串、回调上下文的拥有与有效期必须明确；同步回调靠函数值里的运行期地址，它只在这条线程、这次调用里有效，不能缓存成通用机器入口。
