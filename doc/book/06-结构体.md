# 第 6 章 结构体

<!-- LANGUAGE NAVIGATION -->
[English](en/06-structs.md) · **简体中文**
<!-- END LANGUAGE NAVIGATION -->

一个学生有名字和分数。把它们放在两个毫无关系的变量里，程序越长，就越容易把一个人的名字和另一个人的分数配错。结构体让这些相关的值作为一个整体出现。

## 6.1 先把字段放在一起

<!-- verify-book -->
```chali
struct Student
{
    String name;
    int64 score;
}

void main()
{
    Student student;
    student.name = "Ada";
    student.score = 70;
    println("{} {}", student.name, student.score);
}
```

```text
Ada 70
```

先读声明部分。struct 表示定义一种结构体，Student 是新类型的名字。花括号里的两行是字段：每个 Student 值都带有自己的 name 和 score，两个字段分别使用已有的 String 和 int64 类型。

再读 main。`Student student;` 声明一个这种类型的值。接下来的点号选择这个值的字段，再把名字和分数写进去。最后一行读取的也是 student 的两个字段。类型名和变量名大小写不同，前者说明“是哪一种”，后者说明“是哪一份”。

## 6.2 给类型增加一项操作

在 Student 的字段声明之后加入：

```chali
void addBonus(int64 bonus)
{
    self.score += bonus;
}
```

这仍是一个函数，只是写在类型里，称为方法。参数 bonus 由调用方提供；self 表示接收这次调用的对象。`student.addBonus(5);` 会把 student 的 score 增加 5。若另有一个 Student 值，它不会因此自动得到奖励。

这里返回 void，因为方法只做修改。想交回一个值，就像普通函数一样写出返回类型，并使用 return；不要仅从点号调用推测它是否返回新对象。

## 6.3 把初始化收进入口

每次创建学生都手写字段赋值，会重复相同的准备工作。可以给类型增加一个具名构造入口：

<!-- verify-book -->
```chali
struct Student
{
    String name;
    int64 score;

    static Student create(String name, int64 score)
    {
        self.name = name;
        self.score = score;
        return self;
    }
}

void main()
{
    Student student = Student::create("Ada", 70);
    println("{} {}", student.name, student.score);
}
```

```text
Ada 70
```

先看 create 的头部：它属于类型，因此带 static；返回类型就是正在构造的 Student。构造体内两条赋值把形参存入新结果的字段，`return self;` 结束初始化并交回这个结果。

main 中的 `Student::create` 通过类型调用，不需要先有一个 student。`::` 在这里选择类型上的入口；前面的 `student.addBonus` 则通过已有对象调用实例方法。

这种构造体里的 self 有专门含义，不是任何静态函数都能使用。普通静态辅助函数仍然需要显式参数，不能任意访问某个对象的字段。

## 6.4 一步一步设计数据

先选择对象需要保存的字段，再写操作这些字段的方法。暂时不用为了以后可能出现的需求，把泛型、派生和容器全放进这个小模型。第 7 章先用 Student 观察复制后的关系，第 18 章再让字段类型变化，第 24 章再讨论自动派生方法。

## 6.5 习题

1. 增加一个 className 字段并输出。
2. 创建两个 Student，只修改其中一个的 score，观察另一份。
3. 把 addBonus 改为返回修改后的 int64 分数。
4. 比较 Student::create 与 student.addBonus 调用时各自已经具备哪些数据。

### 参考解答与验收要点

1. 在类型里声明 String 字段，创建值后赋值，再添加一个输出实参。
2. 两个普通拥有值分别保存自己的字段。
3. 返回类型改成 int64，在加分以后 `return self.score;`。
4. create 从形参初始化新结果；addBonus 已经有接收者，只需再提供奖励值。

## 6.6 番外：木兰的行装

改写自北朝民歌《木兰诗》。

唧唧复唧唧，木兰改类型。不闻敲键声，唯闻编译鸣。问女何所思，问女何所忆。女亦无所思，女亦无所忆：昨夜见军帖，可汗大点兵；十二份清单，份份不同名。

阿爷无大结构，木兰无统一型。愿为市结构，从此不散拼。东市买 `horse`，西市买 `saddle`，南市买 `bridle`，北市买 `whip`。四个字段收一处，出发先验能不能骑。

旦辞爷娘去，暮宿边界旁。不闻爷娘唤女声，但闻断言报缺项。弟弟拿绳充马鞍，类型检查不相让；可汗催问能出发否，木兰答曰：“字段全，不等于业务上已经齐。”

万里赴调用，关山度若飞。朔气传日志，寒光照错误。将军百战归，项目十年催。归来见天子，天子问何需。木兰不用加接口，愿借格式化工具，把十二张清单改回一个结构体。

爷娘闻女来，出郭相扶将；阿姊闻妹来，当户改文档；小弟闻姊来，磨刀霍霍向重复字段。同行十二年，不知她的副本早已独立；只因阿爷在家改备注，木兰阵前未受影响。

雄兔脚扑朔，雌兔眼迷离；双兔傍地走，先查模型，安能只凭字段名辨我是公是私？

### 技术对照

结构体组织相关字段和行为，但不会自动获得业务有效性。默认值、构造方式和方法应共同维持不变量；派生能力只覆盖对应协议。
