# 第 3 章 变量与类型

<!-- LANGUAGE NAVIGATION -->

<!-- END LANGUAGE NAVIGATION -->

假设我们正在记录一次考试成绩。最初是 70 分，复核以后增加 5 分。程序必须记住一个值，还要允许后面的语句找到它。变量就是从这里开始的。

## 3.1 给值起名字

<!-- verify-book -->
```chali
void main()
{
    int64 score = 70;
    score += 5;
    let count = 2;
    const int64 limit = 100;
    println("{} {} {}", score, count, limit);
}
```

```text
75 2 100
```

从 main 的第一条语句读起。`int64 score = 70;` 声明一个叫 score 的变量，选择 int64 整数类型，并把初值设为 70。等号右边先产生值，再用它初始化左边的新变量。

`score += 5;` 使用已经存在的变量，把当前值加上 5 再写回。它和声明不同：这里没有创建第二个 score，也没有更换类型。执行之后，score 的值是 75。

`let count = 2;` 让编译器根据右边推导类型。count 仍有具体类型，并不是以后可以随意装入字符串的盒子。`const int64 limit = 100;` 则限制后面对 limit 的修改；推导类型和限制修改是两件事。

最后一行有三个 `{}`。它们按顺序取三个实参，所以分别得到 75、2 和 100。请把 score 的初值改成 60，先推算新的第一项，再运行核对。

## 3.2 先选表示，再做计算

常见整数有 int8、int16、int32、int64 及对应的 uint 类型。数字表示位宽，u 表示无符号；它们能表示的范围不同。日常计数先用 int64，遇到文件格式、外部接口或明确的范围约束时，再考虑其他宽度。

float32 和 float64 表示浮点数，bool 表示 true 或 false。char 与 String 也不是同一种类型：`'A'` 是字符字面量，`"A"` 是字符串字面量。字符串的文本操作在第 12 章展开。

下面的程序稍长。先看两个 floatingKind 函数：它们名字相同，参数类型不同，分别返回 32 和 64。现在把它们当成观察类型的小标签，函数和重载会在下一章解释。

<!-- verify-book -->
```chali
int64 floatingKind(float32 value)
{
    return 32;
}

int64 floatingKind(float64 value)
{
    return 64;
}

uint64 unsignedValue(uint64 value)
{
    return value;
}

void main()
{
    let one = 1u;
    let single = 1.0f;
    uint8 narrow = 255u;
    uint64 maximum = 18446744073709551615u;
    println("{} {} {} {}", unsignedValue(one), floatingKind(single),
            floatingKind(1.0), narrow);
    println("{}", maximum);
}
```

```text
1 32 64 255
18446744073709551615
```

第一段声明函数，运行到 main 以前不会因为写下函数体就打印任何东西。main 中 `1.0f` 的 f 指定 float32，`1.0` 默认使用 float64，因此两次调用显示不同标签。

接下来的一组整数声明展示无符号值。uint8 的 255 和 uint64 的最大值分别适合它们的表示范围；带 u 不意味着可以忽略左边的范围。第一条 println 按调用顺序显示四个观察结果，第二条打印完整的大整数。

整数也能写成十六进制等形式，例如 `0xff`；下划线可以帮助分组，例如 `1_000`。这些写法改变表示文字，不会额外扩大目标类型的容量。完整后缀与字面量形式可以到附录 C 查阅，不必在这里一次背完。

## 3.3 表达式产生值

`score + 5` 是表达式，计算以后得到一个值；`score = score + 5;` 是使用它更新变量的语句。括号可以明确先后顺序，比如 `(2 + 3) * 4` 得到 20。比较 `score >= 60` 产生 bool，下一步可以用它决定走哪个分支。

类型转换也会产生值。下面先保留 original，再把它转换成较窄的整数：

<!-- verify-book -->
```chali
void main()
{
    int64 original = 42;
    int32 narrowed = cast<int32>(original);
    println("{}", narrowed);
}
```

```text
42
```

第一条声明保存原数。两种转换写法分别说明“把这个值解释为目标类型”；它们不会修改 original。最后的输出把原数和转换结果放在一起，便于核对。

把 42 转换成 int32 不难，因为它在范围内。但“可以写转换”不等于“输入一定合适”。假如这里记录金额，应该先判断金额是否符合业务范围，再决定能否缩窄类型；转换不会替你完成这个判断。

## 3.4 名字也有所在的位置

一对花括号可以形成局部作用域。里面的变量主要在这个范围内使用；离开它以后，不能继续假设名字仍然可见。我们会在函数、引用和资源的章节中反复利用这个规则。

读取一个变量时，试着回答四个问题：它叫什么、是什么类型、当前是什么值、能否通过这个绑定修改。这样读代码，比只找等号左右的数字更可靠。

## 3.5 习题

1. 把第一个例子的 score 初值改成 60，写出预期输出。
2. 去掉 count 前面的 let，改写成显式类型声明。
3. 为什么 `const int64 limit = 100;` 后面不能随意给 limit 赋新值？
4. 给 70 分增加 5 分以后，用一个 bool 变量记录它是否达到 60 分。

### 参考解答与验收要点

1. 第一项变成 65，其余两项不变。
2. 可以写 `int64 count = 2;`，初值和后面的输出不变。
3. const 对绑定施加了只读限制；它不是运行后才检查的约定。
4. 可以写 `bool passed = score >= 60;`。比较产生 bool，score 的值仍是 75。

## 3.6 番外：小杯装不下鲲鹏

改写自《庄子·逍遥游》。

北冥有数，其名为鲲。鲲之大，不知其几千亿也；化而为数组，其名为鹏。鹏之大，不知其几千万项也。怒而分配，其请求若垂天之云。

《齐谐》者，志怪者也。《谐》之言曰：“鹏之申请内存也，水击三千行，抟报错而上者九万层，去以六个月之预算者也。”

蜩与学鸠笑之曰：“我决起而算，抢一个 `int8` 而止，时则不至，而控于地而已矣，奚以九万亿为？”它们用一只八位小杯接住账房递来的总数，杯沿顿时溢得满地都是。学鸠擦干桌面，宣布问题已解决，因为屏幕上又出现了一个小数字。

朝菌不知晦朔，蟪蛄不知春秋，窄整数不知业务总额。小知不及大知，小类型装不下大输入，奚以知其然也？看一下范围便知。

鹏说：“且夫水之积也不厚，则其负大舟也无力。你连数值上界都没写，怎么负得动年终报表？”

蜩取出一张显式转换，说自己已经签字，溢出应当自理。庄子叹道：“此亦类型之辩也。签字说明你想倒进去，不说明杯子忽然长成了海。”

### 技术对照

数值类型同时规定表示范围和运算行为。显式转换表明转换意图，并不自动证明输入落在目标范围内；先检查边界，再选择表示类型。
