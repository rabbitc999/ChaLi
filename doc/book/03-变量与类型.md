# 第 3 章 变量与类型

<!-- LANGUAGE NAVIGATION -->
[English](en/03-variables-types.md) · **简体中文**
<!-- END LANGUAGE NAVIGATION -->

变量把名字、类型和当前值联系起来。以成绩为例，先确定要保存整数分数还是带小数的测量结果，再选择表示类型；类型推导省去重复书写，不替代这个数据建模决定。

## 3.1 声明、赋值与推导

显式类型写在名字之前。let 根据初始化式推导类型，const 限制通过该绑定修改值。推导后的变量仍有具体类型，后续赋值遵守相同的兼容规则。普通 const 与编译期可求值表达式也应区分：需要常量长度等场景时，表达式还要满足常量求值限制。

<!-- verify-book -->
```chali
void main()
{
    int64 score = 70;
    score += 5;
    let count = 2;
    const int64 limit = 100;
    println("{} {} {}", score, count, limit);
}
```

```text
75 2 100
```

## 3.2 数值、布尔与文本

整数类型按位宽和有无符号区分，float32／float64 表示浮点数。bool 用于条件，char 表示字符值，String 保存 UTF-8 字节序列。不要把字符个数、字节数与整数取值范围当成同一概念。浮点计算存在表示误差；精确十进制、大整数等需求查相应标准库。

无其他约束的整数字面量通常按 int64 处理；后缀、目标类型与重载选择会影响具体类型。下例用重载观察浮点字面量，并展示不同整数范围。

<!-- verify-book -->
```chali
int64 floatingKind(float32 value)
{
    return 32;
}

int64 floatingKind(float64 value)
{
    return 64;
}

uint64 unsignedValue(uint64 value)
{
    return value;
}

void main()
{
    let one = 1u;
    let single = 1.0f;
    uint8 narrow = 255u;
    uint64 maximum = 18446744073709551615u;
    println("{} {} {} {}", unsignedValue(one), floatingKind(single),
            floatingKind(1.0), narrow);
    println("{}", maximum);
}
```

```text
1 32 64 255
18446744073709551615
```

## 3.3 转换写在表示边界

将 int64 保存为 int32 可能丢失范围，因此缩窄转换需要显式表达。可使用 `(int32)value` 或 `cast<int32>(value)`。允许的隐式转换和字面量范围检查见语言参考；显式强转也不是业务范围校验，输入仍应按应用规则验证。

<!-- verify-book -->
```chali
void main()
{
    int64 original = 42;
    int32 narrowed = cast<int32>(original);
    println("{}", narrowed);
}
```

```text
42
```

## 3.4 作用域与后续使用

同一个名字在不同作用域可以表示不同绑定。读取变量前需要完成初始化；移动后的可用性另由所有权规则约束。下一步将这些值放入函数参数和返回类型中，观察类型如何约束调用。

## 3.5 习题

1. 把成绩改成 float64 并输出。
2. 比较 let 和 Any。
3. int64 到 int32 为什么要考虑范围？
4. const 是否等同于编译期执行？

### 参考解答与验收要点

1. 改变类型和初始化式，核对小数输出。
2. let 推导具体类型；Any 是显式的类型擦除值。
3. 目标表示范围较小；先按业务要求检查，再决定转换。
4. 不同。常量求值另有允许的表达式和计算预算。

## 3.6 番外：小杯装不下鲲鹏

改写自《庄子·逍遥游》。

北冥有数，其名为鲲。鲲之大，不知其几千亿也；化而为数组，其名为鹏。鹏之大，不知其几千万项也。怒而分配，其请求若垂天之云。

《齐谐》者，志怪者也。《谐》之言曰：“鹏之申请内存也，水击三千行，抟报错而上者九万层，去以六个月之预算者也。”

蜩与学鸠笑之曰：“我决起而算，抢一个 `int8` 而止，时则不至，而控于地而已矣，奚以九万亿为？”它们用一只八位小杯接住账房递来的总数，杯沿顿时溢得满地都是。学鸠擦干桌面，宣布问题已解决，因为屏幕上又出现了一个小数字。

朝菌不知晦朔，蟪蛄不知春秋，窄整数不知业务总额。小知不及大知，小类型装不下大输入，奚以知其然也？看一下范围便知。

鹏说：“且夫水之积也不厚，则其负大舟也无力。你连数值上界都没写，怎么负得动年终报表？”

蜩取出一张显式转换，说自己已经签字，溢出应当自理。庄子叹道：“此亦类型之辩也。签字说明你想倒进去，不说明杯子忽然长成了海。”

### 技术对照

数值类型同时规定表示范围和运算行为。显式转换表明转换意图，并不自动证明输入落在目标范围内；先检查边界，再选择表示类型。
