\chapter{标准库速查}
\label{ch:appB}

ChaLi 的「标准库」不是一堆函数，而是一组模块：除核心 \texttt{std:\allowbreak{}:\allowbreak{}lang} 自动加载外，其余都得先 \texttt{import}。这份附录按能力域把它们列一遍，让你知道「想干这件事，该去 \texttt{import} 谁」；每个模块的完整签名与错误边界，去\href{https://github.com/rabbitc999/ChaLi/blob/master/doc/library/README.md}{库函数 API 参考}查。

终端中可以直接用 \texttt{chali man} 查模块，用 \texttt{chali man 模块:\allowbreak{}:\allowbreak{}符号} 查签名、说明和示例；命令说明见\href{https://github.com/rabbitc999/ChaLi/blob/master/doc/man/README.md}{命令行手册}。本附录按当前 API 索引维护，不替代逐项接口参考。

\section{先看一个例子}

\par
\medskip
\begin{lstlisting}[style=chali]
import std::math;
import std::text;
import std::iter;

void main()
{
    println("sqrt={}", std::math::sqrt(144.0));
    println("upper={}", std::text::Text::toUpper("chali"));
    int64 sum = 0;
    for (int64 v in std::iter::range(1, 5))
    {
        sum += v;
    }
    println("sum={}", sum);
}
\end{lstlisting}
\par
\medskip

\par
\medskip
\begin{lstlisting}[style=out]
sqrt=12
upper=CHALI
sum=10
\end{lstlisting}
\par
\medskip

三行分别来自三个模块：数学、文本、迭代。注意 \texttt{range(\allowbreak{}1,\allowbreak{} 5)\allowbreak{}} 是左闭右开 （拿到 1、2、3、4），所以 \texttt{sum} 是 10。其他 API 的端点、索引和失败方式按各自参考页核对。

\section{三条容易踩的约定}

一、资源按类型的生命周期管理。 拥有型对象按 \texttt{Drop} 约定自动释放，提前释放使用类型提供的接口。不能假定所有对象都有相同的 \texttt{close(\allowbreak{})\allowbreak{}} 或重复关闭行为。独占文件、连接、进程和 arena 不能随意复制；转移所有权写 \texttt{move value}。复制是否深复制、借用何时失效，查对应类型的参考页。

二、压缩结果是二进制，不是文本。 \texttt{std:\allowbreak{}:\allowbreak{}compress} 的输出含 \texttt{\textbackslash{}0} 字节，类型是\texttt{List<\allowbreak{}uint8>\allowbreak{}}；别拿它当字符串打印，解压出来的才是 \texttt{std:\allowbreak{}:\allowbreak{}lang:\allowbreak{}:\allowbreak{}String}。

三、字节与码点分清。 \texttt{String} 的长度和切片端点按字节计算，切片可以截取多字节编码的一部分；普通字符串下标仍要求 UTF-8 字符边界。按 Unicode 码点处理时使用显式码点接口或 \texttt{std:\allowbreak{}:\allowbreak{}utf8}。

实际文件、网络、数据库和线程能力以运行期胶水、系统库及构建配置为准。本表列出的是标准库的完整面貌；\href{https://github.com/rabbitc999/ChaLi/blob/master/doc/38-aot.md}{AOT 入口}已覆盖全部条目，但个别能力仍受目标平台限制，编译时以实际诊断为准确认。
