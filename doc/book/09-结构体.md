# 第 9 章 结构体

到这里我们攒了一堆零散的东西：`int64`、`String`、`List`……它们描述的都是**单个**值。
真实程序里，数据往往是**成组**出现的：「一个玩家」有名字和分数，「一个点」有横纵坐标。

结构体（`struct`）就是把一组字段和一组行为收进一个名字下面的东西。

---

## 9.1 定义与使用

```magel
struct Point {
    int64 x;
    int64 y;
};

int64 main() {
    Point p;
    p.x = 3;
    p.y = 4;
    println("{},{}", p.x, p.y);
    return 0;
}
```

```text
3,4
```

拆开看：

```text
struct Point {        ← struct 名字 { 
    int64 x;          ← 字段：类型 名字;
    int64 y;
};                    ← 必须有的分号
```

**最后那个分号很容易忘。** 忘了它，编译器会说「期望分号，实际是……」，
指的位置却是**下一个声明**：

```text
语法错误：hello.mgl 第 2 行第 1 列：期望 分号(;)，实际是 整数类型(int64)
```

看到这种「下一个声明的位置报缺分号」，先回头数一数上一段是不是少了个 `}` 后面的 `;`。

用法：**声明一个变量，然后用 `.` 访问字段**（片段，`Point` 假定已定义）。

<!-- no-run -->
```magel
Point p;          // 声明
p.x = 3;          // 写字段
println("{}", p.x);   // 读字段
```

**没赋过值的字段是 0**，不是垃圾：

```magel
struct Point {
    int64 x;
    int64 y;
};

int64 main() {
    Point p;
    println("[{}][{}]", p.x, p.y);
    return 0;
}
```

```text
[0][0]
```

这条和很多 C 系语言不同——那里的未初始化字段是随机值。Magel 帮你清零了。

> **字段没有「声明处的默认值」。** 写 `int64 retries = 3;` 在结构体里是语法错误。
> 想要默认值，用构造器（9.4 节）。

---

## 9.2 方法：把动作也收进去

字段旁边可以直接写方法：

```magel
struct Point {
    int64 x;
    int64 y;

    int64 sum() {
        return self.x + self.y;
    }

    void shift(int64 delta) {
        self.x = self.x + delta;
    }
};

int64 main() {
    Point p;
    p.x = 1;
    p.y = 2;

    p.shift(10);
    println("{} {}", p.sum(), p.x);
    return 0;
}
```

```text
13 11
```

两条要点：

**方法体里用 `self` 指「这个对象自己」。** 字段不能裸写，得写 `self.x`。
这条规则比 C++ / Java 严格——那里写 `x` 就当 `this->x` 了。Magel 要求你写出来，
因为**一眼能看出哪个名字是字段、哪个是参数或者局部变量**。

**方法定义在结构体的花括号里**，和字段混在一起，不用另开一段。
（有些语言要在结构体外面再写一遍 `impl` 块，Magel 不用。）

调用的写法是 `p.shift(10)` —— 用 `.`，因为 `p` 是一个**具体的对象**。
（`::` 是留给「属于类型、不属于对象」的东西的，下一节。）

## 9.3 `static`：属于类型，不属于对象

有些东西和「某一个具体对象」无关，只跟类型有关。比如「一共造过多少个 Counter」——
这个数不是某个 `Counter` 的字段，它是 `Counter` **这个类型**的。

```magel
struct Counter {
    static int64 alive;
    int64 value;

    Counter(int64 initial) {
        self.value = initial;
        Counter::alive = Counter::alive + 1;
    }

    static int64 count() {
        return Counter::alive;
    }
};

int64 main() {
    Counter c = new(7);
    println("value={} alive={}", c.value, Counter::count());
    return 0;
}
```

```text
value=7 alive=1
```

对照着看两种东西：

| | 写法 | 访问方式 | 属于谁 |
| --- | --- | --- | --- |
| 实例字段 / 方法 | `int64 value;` | `c.value` | 某一个对象 |
| 静态字段 / 方法 | `static int64 alive;` | `Counter::alive` | 类型本身 |

**`.` 和 `::` 的区别就是「对象」和「类型」的区别。** 记住这条，很多报错就看得懂了。

`static` 方法里**没有 `self`**——因为它不属于任何对象。想用实例字段？不行。

## 9.4 构造器与 `new(...)`

字段没赋过值是 0，但我们常常想要「造出来就是对的」。这就是构造器：

```magel
struct Counter {
    int64 value;

    Counter(int64 initial) {
        self.value = initial;
    }
};

int64 main() {
    Counter c = new(7);
    println("{}", c.value);
    return 0;
}
```

```text
7
```

**构造器没有返回类型**，名字和结构体同名。调用它用 `new(实参)`。

两种情形要说清楚（片段，`Counter` 假定已定义）：

<!-- no-run -->
```magel
Counter c = new(7);          // 栈上：跟着作用域走
Counter mut& p = new(7);     // 堆上：要自己 delete
```

**左边写什么类型，就调那个类型的构造器**——`new(7)` 本身不带类型信息。

区别只在左边有没有 `&`：

- 左边是**值**，对象在栈上，出作用域自动清理；
- 左边是**引用**（`Counter mut&`），对象在堆上，**得自己 `delete p;`**（第 8 章）。

想「就地」建堆对象、不写实参时，括号可以省掉：

<!-- no-run -->
```magel
Counter mut& p = new;        // 等价于 new(0)，元素类型由 p 的类型定
```

**`new` 给的是「按目标类型构造」**——目标类型没写，或者那个类型没有匹配实参的构造器，
编译器就报错：

```text
magel：struct Counter 没有匹配的构造函数：(int64)
```

> 📌 **关于 `static T new(...)`**：这是「具名构造入口」写法，允许的。
> 它和普通构造器一样，**隐式带着 `self`**，体里往 `self` 上写字段就行，
> 不用（也不能）写 `return`——返回值由调用点接住。
> **注意调用写法**：`new(3, 4)` 只认真构造器；要用具名入口得写 `Point::new(3, 4)`：

```magel
struct Point {
    int64 x;
    int64 y;

    Point(int64 x, int64 y) { self.x = x; self.y = y; }              // 真构造器
    static Point new(int64 x, int64 y) { self.x = x * 10; self.y = y * 10; }  // 具名入口
};

int64 main() {
    Point o = new(3, 4);          // 真构造器
    Point mut& p = new(1, 2);     // 真构造器 + 堆
    Point q = Point::new(3, 4);   // 具名入口
    println("{},{} {} {} {} {}", o.x, o.y, p.x, p.y, q.x, q.y);
    delete p;
    return 0;
}
```

```text
3,4 1 2 30 40
```

`static X new(...)` 返回所属类型；**丢弃它的返回值会报错**（拥有值的构造结果必须有归属）。

工厂方法的价值在于：**它把「怎么造出一个合法的对象」这件事固定下来**，
调用方不用记住「先 x 后 y」这种细节。

## 9.5 让你的类型支持运算符

想让 `a + b` 这种写法用在自己的类型上，靠**实现内建接口**：

```magel
struct Money : Add<Money, Money> {
    int64 cents;

    Money leftAdd(Money other) {
        Money result;
        result.cents = self.cents + other.cents;
        return result;
    }
};

int64 main() {
    Money a;
    a.cents = 150;
    Money b;
    b.cents = 75;

    Money total = a + b;
    println("{} 分", total.cents);
    return 0;
}
```

```text
225 分
```

`a + b` 被翻译成 `a.leftAdd(b)`。**Magel 里没有 `operator+` 这种声明**——
运算符是「实现哪个接口」决定的：

| 运算符 | 实现接口 | 方法名 |
| --- | --- | --- |
| `+` | `Add<R, T>` | `leftAdd` |
| `==` | `Equal<bool, T>` | `leftEqual` |
| `-x`（一元） | `Negate<R, T>` | `negate` |
| 在容器里当键 | `Hash<T>` | `hash` |

接口是什么、`<R, T>` 里的参数是什么意思——这是第 13 章和第 14 章的内容。
现在你只要知道：**运算符是可以为自己类型定制的，做法是实现接口，不是写 `operator`。**

## 9.6 记住：结构体是**值**

第 6 章那条规则对结构体同样生效，而且这里最容易踩：

```magel
struct Rect {
    int64 width;
    int64 height;
};

int64 area(Rect rect) {
    return rect.width * rect.height;
}

int64 main() {
    Rect r;
    r.width = 3;
    r.height = 4;
    println("{}", area(r));
    return 0;
}
```

```text
12
```

`area(r)` 复制了一份 `r`。对小的 `Rect` 无所谓；**对大的结构体就要写 `Rect const&`**：

<!-- no-run -->
```magel
int64 area(Rect const& rect) { ... }    // 不复制
void resize(Rect mut& rect) { ... }     // 要改
```

另外，结构体可以嵌套结构体，也可以装进容器——**赋值时都是整套复制**，
而且复制是递归到底的（第 6 章）。

结构体还能实现 `Drop` / `Closeable` 来管理资源，那些第 8 章讲过了。

## 9.7 常见错误

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| `期望 分号(;)`，指在下一段声明上 | 结构体结尾漏了 `;` | 补上 `};` |
| `struct X 没有方法 f` | 方法名写错，或者定义忘了写 | 检查拼写与作用域 |
| `不能隐式转换` | 字段类型和赋的值对不上 | 显式强转，或改字段类型 |
| 改不动调用方 | 结构体按值传了 | 形参写 `X mut&`，调用写 `&obj` |
| `X` 没声明的类型 | 忘了写结构体定义，或忘了 `import` | 补上定义 / import |

顺带一句：**结构体的方法里必须写 `self.`**。漏掉会报「找不到这个名字」——
这不是编译器啰嗦，是在帮你区分字段和局部变量。

## 9.8 小结

| 你会了 | 关键点 |
| --- | --- |
| 定义 | `struct X { ... };` —— **结尾分号不能忘** |
| 字段 | 声明后自动清零；不支持声明处默认值 |
| 方法 | 写在结构体里，用 `self.x` 访问字段 |
| `static` | 属于类型，用 `X::name` 访问，里面没有 `self` |
| 构造器 | 与类型同名、无返回类型，用 `new(实参)` 调用（目标类型由左边声明决定） |
| 栈 vs 堆 | `X v = new(实参);` 栈上；`X mut& p = new;` / `new(实参)` 堆上要 `delete` |
| 具名入口 | `X::new(...)` 用 `static X new(...)`；**`new(实参)` 不认它**，它只认真构造器 |
| 运算符 | 实现 `Add` / `Equal` / `Negate` 等内建接口 |
| 传参 | 是复制；大结构体用 `const&` / `mut&` |

---

## 9.9 下一步

结构体解决的是「一组字段永远一起出现」。但还有一类需求它解决不了：

> 一个值**要么是这种，要么是那种**。

比如「一个形状」要么是圆（带半径），要么是方形（带边长）；
「一次操作结果」要么成功（带数据），要么失败（带原因）。

这种「多选一」的数据，是**枚举**的活儿——也是 Magel 里最漂亮的一块。
