# 《ChaLi 程序设计语言》

<!-- LANGUAGE NAVIGATION -->
[English](en/README.md) · **简体中文**
<!-- END LANGUAGE NAVIGATION -->

本书按编写、检查、运行和交付程序的顺序介绍 ChaLi。先通过小程序建立类型与控制流的基本概念，再学习值、引用、资源、泛型和接口，最后组合成数据库应用。正文描述当前 1.0.11 已实现的行为；版本号以仓库 [VERSION](../../VERSION) 为准，未完成计划不作为语法介绍。

## 阅读与运行

没有编程经验的读者可从第 1 章开始。已有经验的读者可借助目录查找专题；第 6 至第 8 章的值、引用和资源规则建议一起阅读。每章末尾提供习题与参考解答。中文番外及技术对照放在章末，英文版只包含技术正文和附录。

完整程序带 main 和预期输出。交互例程另列固定测试输入，终端的输入回显不计入程序输出。短片段用于展示声明或表达式，需要放入相应上下文。错误示例用于说明被拒绝的条件，不应与正常例程合并运行。

命令中的 chali 表示已加入 PATH 的编译器。Windows 源码构建产物带版本、LLVM 变体和平台后缀，执行时换成实际路径；Linux 当前目录的编译器写作 ./chali。安装与平台范围见[安装说明](../39-installation-packages.md)。应用使用的数据库与动态库需单独准备。

可以在线阅读 Markdown，或使用 [PDF](latex/book.pdf)。[英文版](en/README.md) 与中文技术正文对应，不包含番外，也不生成英文 LaTeX/PDF。
