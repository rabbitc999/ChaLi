# 《ChaLi 程序设计语言》

<!-- LANGUAGE NAVIGATION -->
[English](en/README.md) · **简体中文**
<!-- END LANGUAGE NAVIGATION -->

你可以从一个只有四行的程序开始读这本书。先让它输出一句话，再把文字换成自己的名字；等你想让它做更多事情时，我们再引入变量、分支和函数。书里的顺序，就是这个小程序逐渐长大的顺序。

本书面向第一次学习 ChaLi 的读者。有过其他语言的经验会有所帮助，但前几章不会要求你已经理解所有权、泛型或编译器。遇到新写法时，先看它在当前例子里解决什么问题。一个章节不必一次讲完某个词的全部含义，后面会在需要时回来补足。

短例子按语句解释。你会看到某一行保存了什么、下一行为什么改变它，以及输出从哪里来。大程序按功能分段讲解：这一段接收什么数据，做什么工作，怎样把结果交给下一段。建议每读完一小段就改一个输入，先猜结果，再运行核对。

## 三个逐步完成的项目

第 16 章写一个日志检索工具。第一版只在几行文字里查找关键词，再加入文件、命令行选项、行号和错误报告。它没有数据库，也没有界面，便于看清数据怎样从输入走到输出。

第 28 章写一个 HTTP 文件服务器。先接收一次请求，再返回一个文件，随后处理不存在的文件、不支持的方法和并发连接。它只绑定本机地址，协议范围和路径规则会在代码旁说明。

第 29 章阅读并运行学生信息管理系统，把前面学过的模块、接口、错误处理和资源管理用于登录、权限和教务数据。这里会把一个请求从浏览器追踪到数据库，再追踪回响应，而不是只展示目录树。

猜数字是进入语言的第一道小练习。日志工具、文件服务器和学生系统则分别把基础语法、服务程序与综合应用连接起来。可以先顺序读完一个项目，再回头完成章末的改写题。

## 怎样阅读代码

带有 main 的例程是完整程序，代码后紧跟预期输出。交互例子另给输入；输入的终端回显不算程序输出。短片段会说明放在哪个函数或声明里。预期失败的代码会明确指出失败原因，并给出修改方向，不要把它当成正常例程运行。

正文介绍常用写法和它们之间的关系。参数的所有组合、操作符和较少使用的声明形式集中在附录，便于遇到时查找。书中只介绍当前编译器已经实现的语法；ChaLi 与 Rust 的规则有差别，不需要先学 Rust 才能阅读。

安装步骤见[安装说明](../39-installation-packages.md)。命令里的 chali 表示已经放入 PATH 的编译器；如果手里是带版本和平台后缀的文件，就把命令中的 chali 换成那个文件的路径。
