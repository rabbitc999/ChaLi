# 第 5 章 控制流

<!-- LANGUAGE NAVIGATION -->
[English](en/05-control-flow.md) · **简体中文**
<!-- END LANGUAGE NAVIGATION -->

控制流决定哪些语句执行、执行多少次，以及值从哪条路径产生。用条件筛选成绩，再用循环累计；讨论退出规则时，同时观察循环之后的语句。

## 5.1 条件链与条件表达式

if、elif、else 按顺序检查条件，else if 与 elif 等价。条件本身为 bool。条件表达式的分支需要产生兼容的结果类型；语句形式不要求每个分支产生值。

<!-- verify-book -->
```chali
void main()
{
    int32 p = 5;
    bool odd = if (p % 2 == 1)
    {
        true
    }
    else
    {
        false
    };
    int32 category = if (p % 3 == 1)
    {
        1
    }
    elif (p % 3 == 2)
    {
        2
    }
    else
    {
        3
    };
    odd = if (p % 2 == 0)
    {
        false
    }
    else
    {
        bool value = true;
        yield value;
    };
    println("{} {}", odd, category);
}
```

```text
1 2
```

## 5.2 循环累计与区间

for-in 遍历区间或实现迭代协议的对象。range(a,b) 的上界不包含 b；rangeEq 包含上界。while 在每轮前检查条件，loop 依靠循环体中的退出路径。先明确区间端点和状态更新，再计算迭代次数。

<!-- verify-book -->
```chali
void main()
{
    int64 total = 0;
    for (int64 k in range(0, 5))
    {
        total = total + k;
    }
    println("{}", total);
}
```

```text
10
```

## 5.3 从循环取得结果

带值循环使用 yield 产生结果；需要处理未产生结果的路径时使用 else。不要把一个无结果的循环当作整数使用。下例同时展示成功退出和无匹配时的结果。

<!-- verify-book -->
```chali
void main()
{
    int64 found = for (int64 value in range(0, 10))
    {
        if (value > 5)
        {
            yield value;
        }
    }
    else
    {
        yield -1;
    };
    String label = while (false)
    {
        "运行"
    }
    else
    {
        "结束"
    };
    println("{} {}", found, label);
}
```

```text
6 结束
```

## 5.4 退出层级与清理

continue 进入下一轮，break 退出循环。嵌套循环可用 break level N 或 break all 指定退出层级；带值退出还需有相应结果接收者。离开的作用域执行资源清理，第 8 章进一步说明。

自增减和复合赋值会修改目标。避免在一个表达式里安排相互依赖的读写，拆成有明确顺序的语句。

<!-- verify-book -->
```chali
void main()
{
    int64 visited = 0;
    loop
    {
        loop
        {
            visited++;
            break level 2;
        }
        visited += 100;
    }

    int64 total = 0;
    List<int64> values;
    values.push(2);
    values.push(4);
    values.push(6);
    for (item in values)
    {
        total += item;
    }
    println("{} {}", visited, total);
}
```

```text
1 12
```

## 5.5 习题

1. 计算 range(0,5) 的迭代次数。
2. 将同一区间改为 rangeEq。
3. 为无匹配搜索添加结果。
4. 区别 break level 2 与 return。

### 参考解答与验收要点

1. 五次，值为 0 至 4。
2. 包含 5，共六次。
3. 在相应 else 中产生与成功路径兼容的值。
4. 前者退出两层循环，后者结束函数。

## 5.6 番外：桃花源里的 break

改写自陶渊明《桃花源记》。

晋太元中，武陵人以调试为业。缘循环行，忘层之远近。忽逢桃花林，夹岸数百步，中无杂树，唯有日志，落英缤纷。渔人甚异之，复前行，欲穷其源。

林尽水源，便得一山。山有小口，仿佛若有退出条件。便舍舟，从口入。初极狭，才通一个 `break`。复行数十步，豁然开朗——下一轮又开始了。

其中往来种作，男女衣着，悉如外层循环；黄发垂髫，并问：“为什么还没停？”渔人具答之。村人乃大惊，设酒杀鸡作食，说这代码运行六百年了，第一次有人发现刚才只退出了内层。

村中闻有此人，咸来问讯。自云先世避测试，率妻子邑人来此绝境，不复出焉。问今是何世，乃不知有 `break level`，无论函数返回。此人一一为具言所欲退出之层，皆叹惋。

停数日，辞去。此中人语云：“不足为外人道也，尤其别告诉产品经理已经找到出口。”

既出，得其船，便扶向路，处处志之。及郡下，诣太守，说如此。太守即遣人随其往，改了一层嵌套，遂迷，不复得路。南阳刘子骥，高尚士也，闻之，欣然规往；未果，先问清了验收条件。

### 技术对照

break 和 continue 的目标由语法和所在循环决定。修改嵌套结构后必须重新核对目标；带值退出还需要满足所在表达式的结果类型要求。
