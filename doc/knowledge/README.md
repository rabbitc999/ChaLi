# ChaLi 维护知识库

本目录供接手编译器、标准库和编辑器的维护者使用。语言使用者从[书稿](../book/README.md)和[语言参考](../04-language-reference.md)开始。

| 当前任务 | 入口 |
| --- | --- |
| 追踪编译、原生链接、标准库或调试请求 | [实现导航](implementation.md) |
| 构建编译器、生成安装包或核对交付 | [构建与验证手册](release.md) |

接手时先读取 [VERSION](../../VERSION)、[当前能力](../17-capabilities.md)和 [CHANGELOG](../../CHANGELOG.md)，再查看 `git status --short`、当前提交和对应回归。版本取 `VERSION`。性能报告里的构建标识对应测量时的二进制，核对提交、配置和摘要后再引用。

交接记录宜包含复现命令、目标系统与 CPU、使用的编译器路径与摘要、预期和实际结果。分别记录源码检查、目标对象生成、原生或模拟执行、安装包内容核对和真实编辑器宿主测试。遇到尚未验证的场景，记下缺少的环境或输入和可复现的下一步。
