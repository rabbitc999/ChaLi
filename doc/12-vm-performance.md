当前程序版本为 **ChaLi 1.0.6**。

## 1.0.6 最终发行版实测

本轮更新了 AOT、默认容器、自举容器及 VM 基准。AOT 默认 LLVM O3，完整四元式预算、反射、边界和存活检查保留；Windows x64、外置 LLVM 变体完成实际验证。正式计时使用未插桩产物，所有权计数另行采集。

- [P0～P2 同版本优化开关对照](../benchmarks/results/backend-1.0.6/README.md)：8 项负载，包含原始计数、LLVM IR 证据和返回链／分块 List 的追加复测。
- [通用 AOT 与 C++ O3](../benchmarks/results/aot-1.0.6/README.md)：整数链、浮点链、调用、数组读、数组读写及 List。
- [默认容器性能对比](../benchmarks/results/containers-1.0.6/README.md)：12 项负载，交错测量真实 1.0.5／1.0.6 VM、AOT，并加入 C++、Python、Lua。
- [ChaLi 自举容器 AOT 对比](../benchmarks/results/slot-segmented-1.0.6/README.md)：默认容器、原自举数组实现，以及三元组 Map、独立槽位 Set、分块 List。
- [VM 基准](../benchmarks/results/vm-1.0.6/README.md)：沿用标准规模，真实 1.0.5／1.0.6 交错测量。

各报告逐项保留提升、回退和波动，不将减少复制次数直接等同于端到端加速。跨版本 AOT 对照同时包含旧版 O2→新版 O3，不能单独归因某个优化；同版本对照两侧均用 O3。下方历史数据保留原版本、配置和样本。

## 方法与配置

每配置运行 3 次进程，每进程预热 1 次并计时 5 次，每负载共 15 个执行样本；各轮改变配置执行顺序。work 内的建表、分配和清理计入耗时，编译器启动与编译不计入内部计时，进程总耗时和构建耗时仍保存在原始报告中。

| 项目 | 配置 |
| --- | --- |
| 宿主 | Windows-10-10.0.19045-SP0 |
| CPU | AMD64 Family 25 Model 33 Stepping 2, AuthenticAMD, 12 个逻辑处理器 |
| C++ | g++ (x86_64-posix-seh-rev3, Built by MinGW-W64 project) 11.2.0，`-std=c++17 -O2 -DNDEBUG` |
| Python | 3.12.3 (tags/v3.12.3:f6650f9, Apr  9 2024, 14:05:25) [MSC v.1938 64 bit (AMD64)] |
| Lua | Lua 5.5.1 (official VM, monotonic clock host) |
| LLVM | clang version 23.1.4 (https://github.com/llvm/llvm-project.git 7a941dfb2877a0b8cf30323fefa85ad019e0b0f5)，`-O2` |
| VM | 默认最高优化，启用反射，完整四元式优化 maxRounds = 4 |
| AOT | LLVM 机器码，默认保留边界与存活内存检查，复用共享标准库运行时 |

## 默认容器负载

容器元素、键和值均为 int64。每次 work 的主要循环为 50,000 轮，读取和更新负载先填充 1,024 项。构建负载插入不同元素后读取或查询，删除负载建表后清空。Set 读取在 2,048 个键的范围内包含命中和未命中，Set 写入反复插入 1,024 个不同键。所有配置均核对独立闭式公式给出的校验值。

C++ 使用默认增长的 std::vector、std::unordered_map、std::unordered_set，不调用 reserve；Python 使用 list/dict/set；Lua 用 table 表示序列与映射，Set 用键到 true 的映射并维护计数，密集整数键可能走 table 数组区。表格比较这些具体程序及默认分配策略。C++ 计时通过 volatile 函数入口调用 work，防止编译器把计算移出计时区间。

[负载源码与生成器](../benchmarks/perf/container_cases.py)；[测量驱动](../benchmarks/perf/containers.py)
