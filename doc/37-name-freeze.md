# ChaLi 名称与相关能力

[English](en/37-name-freeze.md) · **简体中文**
<!-- END LANGUAGE NAVIGATION -->

本页记录名称写法及常见能力入口。能力范围以当前实现、参考文档和验证结果为准，名称含义不构成对所有平台、外部库或不安全代码的无条件保证。

## 名称与文件

| 项目 | 当前写法 |
| --- | --- |
| 语言名 | ChaLi |
| 源文件 | .chl |
| 诊断码前缀 | CHL |
| 项目配置 | chali.toml |
| 编译器产物 | 版本、LLVM 链接方式、系统与架构组成文件名 |

命令通常写 chali，实际源码构建文件名按 [安装说明](39-installation-packages.md) 使用。历史命名保留在 Git 与 CHANGELOG 中。

## 值、复制与移动

普通值使用独立的可观察值语义，引用字段仍表示借用。显式移动转移拥有权；编译器可以在不改变行为时消除复制或复用存储。不能根据复制语法推断底层每次都执行物理深拷贝。资源型值还受不可复制等约束。见[值与资源](book/06-值语义.md)及[移动](24-ownership-move.md)。

## 宏卫生与求值

宏内部名字与调用方隔离。默认值参数单次求值，修改副本不改变调用者；引用参数与 expr 语法参数各有明确行为。声明宏暂缓，已实现类别见[宏教程](book/19-预处理与宏.md)。

## 类型擦除

Any 保存具体类型信息并通过受检查接口恢复。类型擦除不取消引用来源、所有权和资源规则，也不允许伪造未实现的行为。见 [Any 与泛型](23-any-generics-data.md)。

## 引用有效期

静态检查跟踪引用来源及使用范围。合法程序仍需遵守外部 C ABI 与 unsafe 操作的前提，静态借用检查不能验证任意外部二进制行为。诊断与边界见[引用教程](book/07-引用.md)及[不安全代码](41-unsafe-abi.md)。

## 接口与分派

接口描述行为，具体类型提供实现。接口可以带泛型、继承其他接口，并在 match 中细分具体实现。运行行为由实际接收者决定；已知目标可以被后端静态化或内联，只要可观察行为保持一致。见[接口教程](book/13-接口与运行期多态.md)。

## 验证入口

功能样例位于 [example/samples](../example/samples/)，拒绝案例位于 [example/samples-error](../example/samples-error/)。测试结果需要同时记录源码、编译器、目标与开关。未执行的平台和配置不能根据名称或一个样例推断为已验证。
