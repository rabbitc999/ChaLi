# 后端所有权优化与 AOT 计数

[English](en/43-backend-ownership.md) · **简体中文**

ChaLi 1.0.6 在完成类型、借用和确定性清理的降低后优化聚合传递，主要评估 LLVM AOT。普通赋值的独立值语义，以及 `Copy<T>` 与 `#NonCopyable` 的互斥规则保持不变。

AOT 默认开启全部适用优化，静态 LLVM 使用 `default<O3>` 与激进代码生成等级，外置 LLVM 使用 `-O3`；四元式沿用完整优化预算。保持常规浮点语义，不启用 fast-math。安全适用条件和回退仍然生效，计数插桩默认关闭。

## 聚合目标地址

对已经分配、尚未暴露的新聚合初始化，编译器可以生成内部目标地址变体，让工厂或构造函数直接写入调用者存储，省去中间返回槽的搬运和清槽。元组和枚举构造也可以使用此路径，保留枚举标签初始化。

原函数入口仍供导出、函数值和间接调用使用。覆盖已有对象、自引用初始化、未识别的返回形式及带可观察用户析构的聚合保留原路径。返回已有借用值仍产生必要的独立副本；本优化不是把深复制改成浅复制。隐藏参数是语言运行时的逻辑存储地址，不改变公开 C ABI。

临时聚合接收者也可在自己的新存储中直接构造，完整表达式结束时照常清理。字段或下标读取不因本优化而获得额外拥有权。

单个拥有聚合载荷的枚举构造可以接管已证明独占、没有可观察用户析构的新临时值，清空源拥有槽，避免先深复制再清理该临时值。已有变量、借用值及不满足条件的载荷继续复制。

## AOT 与四元式优化

- 聚合槽复制：整个源、目标范围都活跃且不重叠时批量搬运。重叠或范围证明失败时，回到原顺序的逐槽先读后写，保留越界、悬空及部分写入行为。零长度不访问内存。
- 数组复制：64 位整数与 64 位浮点的平凡元素可走槽复制助手；其他布局和超大计数保留原循环。新数组仍经原有受检分配与初始化，不引入未初始化存储语义。
- 地址验证：仅在直线路径、地址符号和精确访问宽度不变时复用验证结果。调用、分配、释放、控制流边界和内存写入使相应证明失效。
- 重复检查：相同操作数的再次检查仅在本基本块内、没有失效屏障时删除；第一次检查保留原位置。
- 函数调用：对适用的极小内部 AOT 函数提供内联提示；直线路径内已知且无捕获环境的函数值可直接调用。未知目标、闭包环境、重入后失效的事实及间接调用协议保留兼容路径。

看门狗路径保守停用不能证明逻辑安全点等价的快速路径。VM 的非循环调用保持原有入口、断点和调用栈身份。除零、溢出和移位越界等既有运算语义不因这些优化而关闭。

## 可选计数

设置 `CHALI_BACKEND_PROFILE=1` 后编译 AOT 程序，生成的程序会在所有权相关四元式位置记录调用、分配请求、移动及清理。运行时用 `CHALI_BACKEND_PROFILE_OUTPUT` 指定 JSON 输出，正常进程退出后保存所有线程的累计计数。

```powershell
$env:CHALI_BACKEND_PROFILE='1'
chali aot example/samples/backend_ownership.chl --out tmp/ownership-profile
Remove-Item Env:CHALI_BACKEND_PROFILE
$env:CHALI_BACKEND_PROFILE_OUTPUT="$PWD/tmp/ownership-profile.json"
& ./tmp/ownership-profile.exe
python tools/backend_profile.py tmp/ownership-profile.json --top 20
```

默认编译不插入计数调用。插桩产物用于定位成本，正式耗时使用另行构建的未插桩产物。设置输出环境变量不会给普通产物添加插桩。

每项记录包含操作、函数、源文件行号、优化后四元式编号、执行次数和已知请求字节数。计数表示剩余降低操作的执行次数，不是源代码语义复制次数；已经消除的操作不会出现。分配请求字节仅覆盖四元式 `alloc`，不代表所有宿主对象的内部申请、实际存活量或峰值。递归清理助手和底层释放属于不同层级，不应相加当作用户析构次数。原始槽搬运也不等于拥有字段的深复制。

## 对照开关

以下环境变量在编译时非空即保留对应原路径，用于同版本对照，不修改源码：

| 环境变量 | 关闭的优化 |
| --- | --- |
| `CHALI_NO_AGGREGATE_OPT` | 聚合目标地址变体与新临时存储合并 |
| `CHALI_NO_ARRAY_COPY_BULK` | 64 位平凡数组的槽复制路径 |
| `CHALI_NO_AOT_BULK_COPY` | AOT 聚合槽批量复制助手 |
| `CHALI_NO_AOT_ADDRESS_CACHE` | AOT 已验证地址复用 |
| `CHALI_NO_AOT_INLINE_HINT` | AOT 极小函数内联提示 |
| `CHALI_NO_AOT_DIRECT_CALLS` | 已知无环境函数值直接调用 |
| `CHALI_NO_OPT_CHECKS` | 本基本块的重复检查消除 |

其他已有四元式和机器级开关继续有效。优化范围外的场景会回退，不要求用户改写代码或使用不安全操作。
