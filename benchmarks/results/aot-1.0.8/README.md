# ChaLi 1.0.8 LLVM AOT 跨语言基准

Windows x64、外置 LLVM 变体（clang 23.1.4 在 PATH 上，AOT 用 `-O3`）。构建与正式计时隔离，性能阶段串行执行；每配置 5 次进程，每进程 5 个样本，取 25 个样本中位数。源码、规模、校验值与原始样本见 [results.json](results.json)，脚本见 `benchmarks/perf/run.py`。

被测编译器为 1.0.8 外置 LLVM 版，SHA256 `3241a0efd39dd8aee2623e53e5d0cf3ac7c73cae7002ccf3dfb943e23df6ea70`。同一份 ChaLi 计算函数用 `#export` 导出 C ABI，由统一 C 壳计时，进程初始化不计时；C 壳与 `chali aot` 产物用同一个计时函数和 `sink` 归并，只有被测函数不同。C／C++／Rust／Go 为原生机器码，Lua 5.5.1、Java 22（`-Xint` / `-Xbatch`）、Node 26、CPython 3.12 为各自的默认运行方式。

| 配置 | int_chain | float_chain | call | array | list |

单位毫秒，越小越快。ChaLi AOT 相对 C 分别为 21.1、17.7、26.3、25.2、392.7 倍；相对 CPython 则在 list 上一度落后（398.753 对 55.950），说明容器路径比标量路径贵得多。缺省 `chali run`（checked AOT，保留边界与存活检查）与这里的 unchecked 导出相差 0.3%～2.2%，两行都在 [summary.md](summary.md) 里。

这些结果只描述给定源码、规模和本机配置，不代表语言的一般速度。1.0.8 的内嵌资产只提供 AOT 路径，没有 VM 解释执行核可与 AOT 对照。
