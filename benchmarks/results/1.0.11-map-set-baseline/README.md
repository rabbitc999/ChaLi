Map、Set 的跨语言校验值分别为 `6004096376` 与 `2373508172`，均符合驱动的独立算术模型。全部 25 个原始纳秒样本、源码摘要、构建命令、真实工具版本及编译器来源提交保存在 results.json，原始输出在 run.log。

两项均从空集合开始，使用 20000 个离散整数键，覆盖增长、重复操作、命中与缺失、删除和重新插入。具体协议见 ../../perf/COLLECTIONS.md。Lua 用 table 实现映射与集合；C++／Rust 保留各自标准哈希容器和默认哈希策略；不比较不同哈希遍历次序。

本轮为初始基线补测，原五项结果目录不改写。Map 与 Set 仍分别约为 Lua 耗时的 133.7 倍、109.5 倍，集合重构与性能目标仍待推进。静态 LLVM 和交叉运行时不在本轮计时范围内。
