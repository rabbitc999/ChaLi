# ChaLi 1.0.7 LLVM AOT 程序体积对照

Windows x64、外置 LLVM；同一源码分别使用真实 1.0.6 编译器、1.0.7 按需标准库和 1.0.7 全标准库模式构建。所有程序均实际执行并校验输出，默认反射、安全检查及最高优化保留。数字为磁盘文件字节数，不代表运行时内存。

原来的主要磁盘开销来自 CAS 的 64 MiB 零初始化后备池被 MinGW GCC 写入数据段。改为 BSS 后保留池容量，磁盘文件不再保存整块零字节；按需宿主模块选择进一步降低无容器小程序的依赖。List/CAS 等负载会保留实际需要的模块。

外置链路采用 LLVM O3、完整 LTO 与节区回收；静态 LLVM 链路同步配置全局死代码消除和链接回收，但本轮没有静态 LLVM SDK，未执行该变体，不能据此声称静态变体已通过。

[原始数据、源码、编译器与产物 SHA256、PE 节区和模块选择](results.json)保留实际测量快照：1.0.7 的该次体积测试在后续生命周期文档补充前完成，未将编译器 SHA256 重标为最终文档版。
