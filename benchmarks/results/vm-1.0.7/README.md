# ChaLi 1.0.6 与 1.0.7 VM 对照

Windows x64、外置 LLVM，默认最高优化、完整四元式优化预算、反射与安全检查。构建与正式计时隔离，性能阶段串行运行；每配置 3 次进程，每进程 5 个样本，取 15 个样本中位数。规模、源码、校验值与原始样本见 [results.json](results.json)。

测量使用代码定稿快照 1.0.7，编译器 SHA256 `aedbf7d90d805ecedc2e0c6f60e49d11b05af766ddd7c17d0d713b61265f5ea8`。发行前再次核对定稿文档与内嵌资产，交付二进制摘要单独记录；不重标测量摘要。旧版为真实 1.0.6 发行编译器。

真实旧版和新版编译器按轮次交错执行同一源码，沿用 call／array／array_rw／list 标准规模，每次核对校验值。List 超时预算延长至 900 秒，不降低元素数或循环次数。

| 负载 | 1.0.6 ms | 1.0.7 ms | 新／旧 |
| --- | ---: | ---: | ---: |
| call | 58.080 | 48.905 | 0.842× |
| array | 346.803 | 334.115 | 0.963× |
| array_rw | 606.787 | 583.713 | 0.962× |
| list | 851.957 | 21487.057 | 25.221× |

新／旧大于 1 表示新版变慢。容器默认算法迁入语言后，VM 的方法和循环成本明显增加，不能将 AOT 的优化结论外推给 VM。小幅变化也可能包含系统噪声。
