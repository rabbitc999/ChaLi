# ChaLi 1.0.6 后端 P0～P2 实测

同一最终发行编译器分别关闭／默认开启本轮新增优化，LLVM 两侧均为 O3。默认保留边界、存活检查与反射。关闭开关见原始报告 `baseline_flags`，这不是把全部既有优化关闭。

- 平台：Windows x64，外置 LLVM；静态 LLVM 变体仅修改构建路径，未在本机验证。
- 编译器 SHA256：`9f7592fe2b4e219a62b93b2c8f561639314fb8176bd4ef26ae1dfa1d2bfab063`。
- 每组 1,000 次操作；每配置 3 次进程，每进程预热一次、计时五次，取 15 个内部纳秒样本的中位数。
- 全部产物先构建，未插桩程序交错计时，之后另行运行插桩程序采集所有权计数。编译、启动和插桩耗时不计入表中。
- 每次输出按独立闭式公式核对。原始输出、构建命令、校验值、源码 SHA256、LLVM IR 证据和计数见 [results.json](results.json)；生成源码见 sources/。

## 计数

计数覆盖剩余所有权四元式位置，分配请求不是实际存活量，槽位复制不是深复制；不相加不同清理层级冒充析构次数。以下数据来自独立插桩执行，包含预热及五轮执行。

| 负载 | 聚合移动 关闭→默认 | 槽复制调用 关闭→默认 | String 复制调用 关闭→默认 |
| --- | ---: | ---: | ---: |
| return_chain | 12000 → 6000 | 18000 → 12000 | 0 → 0 |
| aggregate_copy | 6006 → 0 | 6012 → 6006 | 6000 → 6000 |
| enum_payload | 12000 → 12000 | 18000 → 18000 | 6000 → 0 |
| scalar_array_copy | 0 → 0 | 0 → 6000 | 0 → 0 |
| field_read | 6 → 0 | 12 → 6 | 0 → 0 |
| function_value | 0 → 0 | 0 → 0 | 0 → 0 |
| small_method | 0 → 0 | 0 → 0 | 0 → 0 |
| segmented_list | 72 → 72 | 312 → 312 | 18012 → 18012 |

枚举载荷负载中的四元式分配请求由 24,001 次降为 18,001 次，String 复制调用由 6,000 次降为 0 次；这是该负载的执行计数，不表示所有宿主分配或峰值内存。
