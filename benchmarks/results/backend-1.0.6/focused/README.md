# 返回链与分块 List 的追加复测

原 1,000 次操作负载出现回退与明显波动，因此追加每负载 10,000 次操作、每配置 5 次进程的复测。其余编译器、O3、反射、安全检查、预热一次及内部五轮规则相同。原报告全部保留；这份追加结果不覆盖原样本。构建、计时、计数顺序仍隔离。

[原始结果](results.json)，源码位于 sources/。比值为关闭新优化／默认优化，大于 1 表示默认更快。

| 负载 | 关闭 ms | 默认 ms | 关闭／默认 |
| --- | ---: | ---: | ---: |
| return_chain | 89.650 | 72.716 | 1.23× |
| segmented_list | 337.108 | 338.854 | 0.99× |

两轮规模和进程次数不同，绝对时间不可直接相除。追加复测用于评估差异是否稳定，不排除宿主调度、频率与后台活动影响。
