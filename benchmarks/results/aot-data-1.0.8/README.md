# 1.0.8 原生体积简单抽查

本轮按用户要求仅简单验证，不运行完整性能、VM 或容器对比套件。完整历史测量保留原版本与原始摘要；1.0.8 已移除 VM 和 `.svmb` 执行路径，不生成新的 VM 性能结果。

`smoke.json` 保存单个相同源码在真实 1.0.7 发行编译器与当前 1.0.8 编译器下的命令、结果、SHA256、LLVM 文件大小和 EXE 大小。源码包含全局零数组、1024 元素局部数组、未使用函数值及字符串、Unicode/空格参数。

测量使用 Windows x64 外置 LLVM、默认最高优化，导出对照为 unchecked。checked run 另外核对输出与检查模式。单例体积变化不能代表所有程序，也不是运行耗时或吞吐性能结论。

最终通过状态和实际字节数以 [smoke.json](smoke.json) 为准。
