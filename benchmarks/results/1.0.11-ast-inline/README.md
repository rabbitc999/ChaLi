上述非交错测量较上一轮慢，尤其 Set。为区分强制展开的影响和时段波动，另用同一个编译器分别构建默认内联与 `CHALI_NO_AOT_INLINE_HINT=1` 产物；全部构建结束后，在每个负载内按开启／关闭、关闭／开启的顺序交错运行。每配置仍是 5 个进程、每进程预热后 5 轮。没有运行其他语言。全部校验值一致。
