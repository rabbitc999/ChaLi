# ChaLi 1.0.5／1.0.6 默认容器对照

Windows x64，默认 List／Map／Set；每负载 50,000 次操作，读取／更新工作集 1,024。包含 work 内的创建、分配、操作与清理。先构建全部产物，再交错执行；每配置三次进程，每进程预热一次、计时五次，共 15 个内部样本。每次结果按闭式公式核对。

1.0.5 AOT 使用旧版默认 O2，1.0.6 使用新版默认 O3；两者均启用反射、完整四元式优化与安全检查。C++17 为 g++ -O2 -DNDEBUG，Python 及 Lua 使用各自默认容器。它们是生态参考，布局、散列与资源管理行为不完全相同。

工具版本、编译器真实版本及 SHA256、源文件 SHA256、构建记录、执行顺序、stdout/stderr、进程总耗时和内部纳秒样本见 [results.json](results.json)。
