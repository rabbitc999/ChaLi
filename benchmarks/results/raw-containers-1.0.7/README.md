# ChaLi 1.0.7 容器三方 AOT 对照

Windows x64、外置 LLVM，默认最高优化、完整四元式优化预算、反射与安全检查。构建与正式计时隔离，性能阶段串行运行；每配置 3 次进程，每进程 5 个样本，取 15 个样本中位数。规模、源码、校验值与原始样本见 [results.json](results.json)。

测量使用代码定稿快照 1.0.7，编译器 SHA256 `aedbf7d90d805ecedc2e0c6f60e49d11b05af766ddd7c17d0d713b61265f5ea8`。发行前再次核对定稿文档与内嵌资产，交付二进制摘要单独记录；不重标测量摘要。旧版为真实 1.0.6 发行编译器。

`native` 是驱动沿用的配置键，实际为 **1.0.7 默认 ChaLi 自举算法＋宿主单槽存储边界**；`baseline` 是 1.0.6 原生 C++ 算法；`bootstrap` 是独立实验原始存储实现。不能把本版默认实现称为原生 C++。

实验实现：[raw_containers.chl](../../perf/raw_containers.chl)。int64 元素与键，1024 次操作；备用容量不构造元素，List 删除清理元素并保留容量。Map 使用缓存 HashKey／Value／HasValue 槽及回移删除，Set 独立保存槽位数组；哈希经过 SplitMix64 终结混合后取模。建表、分配和清理计入 work，编译不计时。

首轮仅对整数取模的真实结果保留在 [modulo-hash-initial.json](modulo-hash-initial.json)，原型为 [raw_containers_modulo.chl](../../perf/raw_containers_modulo.chl)。连续键造成长占用区和回移扫描；混合哈希缓解该负载，但仍须与默认及旧版逐项比较。
