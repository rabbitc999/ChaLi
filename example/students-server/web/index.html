开始工作

    数据维护顺序

    1. 管理员建立班级与科目。
    2. 建立教师、学生账号，并关联对应资料。
    3. 在权限管理中配置教师授课班级与科目。
    4. 教师录入成绩，学生登录查看自己的记录。
    管理员管理账号与基础资料；教师仅维护已授权班级、科目的成绩；学生只读自己的资料与成绩。停用账号、修改角色或口令后，已有会话失效。
